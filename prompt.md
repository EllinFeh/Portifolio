# 1. Antes de desenvolver

Antes de escrever código:

1. Analise toda a estrutura do projeto atual.
2. Identifique:
   - tecnologias utilizadas;
   - páginas;
   - componentes;
   - assets;
   - textos;
   - dados pessoais;
   - projetos;
   - links;
   - arquivos reaproveitáveis;
   - problemas arquiteturais.
3. Não replique automaticamente a arquitetura antiga.
4. Utilize o projeto atual apenas como fonte de dados e referências.
5. Proponha internamente uma nova arquitetura baseada em Next.js + TypeScript.
6. Depois disso, faça a migração/refatoração.

O resultado precisa parecer um projeto novo.
